# Quiet Eye Under Pressure

**The Eyes Don't Lie. Pressure Makes Them Wander. Train Them to Stay.**

---

## The Pressure Effect on Quiet Eye

| Pressure Level | QE Duration | QE Timing | Result |
|----------------|-------------|-----------|--------|
| **Low** | 300ms+ | Early park, late release | Consistent |
| **Medium** | 150-300ms | Later park, earlier release | Variable |
| **High** | <150ms | No park, tracking to contact | Errors, choking |

**Pressure shrinks the Quiet Eye window. Your job: defend it.**

---

## Why QE Fails Under Pressure

| Mechanism | What Happens |
|-----------|--------------|
| **Anxiety → Attention shift** | Focus moves from *task* (ball) to *threat* (outcome, opponent, score) |
| **Working memory overload** | Conscious control tries to "help" → disrupts automatic motor programs |
| **Vestibular arousal** | Heart rate up → head micro-movements → VOR noise → face instability |
| **Visual search** | Eyes hunt for reassurance (target, opponent, lines) → lose contact zone |

---

## The QE Pressure Protocol

### 1. Pre-Point: Defend the Park
- **Routine** locks QE in before pressure hits
- **Feet → Head → Hands → Breath → Eyes** creates automaticity
- **Eyes park** becomes habit, not decision

### 2. During Rally: The QE Anchor
```
Opponent hits  →  EYES PARK (say "park")  →  Hold through contact  →  Release
```
**Verbal anchor** ("park") keeps conscious mind occupied on task, not threat.

### 3. Training QE Under Pressure

#### Drill: "Pressure Park"
1. Partner feeds balls at match pace
2. **Consequence:** Miss park = pushup. Make park = point.
3. Score to 11. Track park %.
4. **Target: >85% park rate under consequence.**

#### Drill: "Fatigue Park"
1. 20 burpees / 30 sec sprint
2. Immediate ball feed
3. Must park within 100ms of opponent contact
4. **Simulates late-match vestibular fatigue.**

#### Drill: "Scoreboard Park"
1. Play practice sets
2. **Only score points where QE verified** (coach/partner confirms)
3. Non-park points = replay
4. **Rewires brain: QE = scoring.**

## The QE Pressure Checklist

**During match, after each point:**

| Question | Yes/No | Fix if No |
|----------|--------|-----------|
| Did I park at opponent contact? | | Next point: verbal "PARK" |
| Did I hold through my contact? | | Next point: count "1-2" after contact |
| Did I release only after ball crossed net? | | Next point: "Hold. Cross." |
| Was head still? | | Chin tuck mantra + breath |
| Was face angle stable? | | Check grip pressure (3/10) |

---

## Emergency QE Reset (Mid-Match)

**When: 3+ unforced errors, tightness, "can't see the ball"**

1. **Walk to fence** (10 steps)
2. **Eyes closed** - 3 slow breaths
3. **Visualize** perfect park on next ball (10 sec)
4. **Verbal:** "Eyes. Park. Hold. Trust."
5. **Step up.** Next point: exaggerated routine (+5 sec)

---

## QE Under Specific Pressures

| Pressure Type | QE Threat | Defense |
|---------------|-----------|---------|
| **Break point down** | Eyes rush to target | Routine + "Park" anchor |
| **Set point up** | Early celebration glance | "Hold. Cross." mantra |
| **Tiebreak** | Sustained arousal | Breath every point. Micro-reset. |
| **Wind/sun** | Visual noise | Longer park. Trust feel. |
| **Bad line call** | Anger → visual search | Release ritual. "Done. Next." |
| **Fatigue (3rd set)** | Vestibular noise → head drift | Extra breath. Chin tuck focus. |

## The QE Pressure Mantra

> **"Park early. Hold late. Trust always."**
