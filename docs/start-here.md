# Start Here

**New to the system? Start with these three steps.**

---

## Step 1: Understand the Map

The entire system is built on **12 variables** that form one chain:

```
Q → V → ROOT → F → P → T → SSC → 8 → 45° → BRAKE → PULSE → JIN
```

**Read: [The CORE Map →](/system/core-overview/)**

---

## Step 2: Find Your Broken Link

Every stroke error traces to **one broken variable**. The diagnostic takes 5 minutes.

**Take: [The CORE Diagnostic →](/resources/diagnostics/)**

| Your Symptom | Likely Broken Link |
|--------------|-------------------|
| Late contact, shanks | **Q** (Quiet Eye) |
| Head moves, balance off | **V** (Vestibular) |
| No power, falling back | **ROOT** (Rooting) |
| Arm-only swing, elbow pain | **F/P** (Fascia/Proprioception) |
| Muscled swing, no whip | **T/SSC** (Tensegrity/SSC) |
| Big takeback, late contact | **8** (Figure-8) |
| Flat balls, no margin | **45°** (Swing Plane) |
| No penetration, pushy | **BRAKE/PULSE** |
| Inconsistent under pressure | **JIN** |

---

## Step 3: Follow the Path

| Your Starting Point | Your Path |
|---------------------|-----------|
| **Recreational / Club** | CORE Map → Diagnostics → Forehand Push → Serve/Return |
| **Competitive / Tournament** | Diagnostics → Your weakest variable → That variable's chapter → Drills |
| **Coach / Teacher** | CORE Map → Visual Library → Drills Library → AI Coach integration |
| **High Performance** | Full system → Variable deep-dives → Pattern training → Mental/Physical |

---

## The Three Rules

1. **No variable works alone.** The chain is only as strong as its weakest link.
2. **Don't skip links.** You cannot fix PULSE if ROOT is broken.
3. **Train the chain, not the parts.** Every drill connects to the full chain.

## Your First Week

| Day | Focus | Action |
|-----|-------|--------|
| 1 | **The Map** | Read [CORE Overview](/system/core-overview/) — understand all 12 variables |

| 5 | **Integrate** | Shadow swings + [Figure-8 drill](/resources/drills/#figure-8) — feel the chain |
| 6 | **Play** | Play points — use [Pre-Point Routine](/mental/routine/) on every point |
| 7 | **Review** | Film 5 forehands/backhands — compare to [Visual Library](/resources/visual-library/) |
