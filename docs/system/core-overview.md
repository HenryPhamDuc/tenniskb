# The CORE System Overview

**The complete Q-V-ROOT-8-45-Impulse-Jin chain — all 12 variables in one view.**

---

## The Chain

```
Q → V → ROOT → F → P → T → SSC → 8 → 45° → BRAKE → PULSE → JIN
```

Every variable is a link. **Break one, the chain fails.** Master all twelve, the stroke becomes inevitable.

## The CORE Equation

```
CORE = Q + V + ROOT + 8 + BRAKE + PULSE
```

**CORE** is the operational subset — the six variables you actively manage **on every shot**.

| Variable | Role in CORE |
|----------|--------------|
| **Q** | Locks the external target |
| **V** | Keeps the platform stable |
| **ROOT** | Anchors the kinetic chain |
| **8** | Guarantees no pause (SSC) |
| **BRAKE** | Creates the impulse |
| **PULSE** | Releases the energy |

**F, P, T, SSC, 45°, JIN** are the **foundation** — built in training, expressed in CORE.

## Quick Diagnostic

| Symptom | Broken Link | Fix |
|---------|-------------|-----|
| Late contact, shanks | **Q** | Park eyes at bounce |
| Head lifts, face opens | **V** | Chin tucked, eyes parked |
| No power, falling back | **ROOT** | Screw feet, lift arch |
| Arm-only, elbow pain | **F/P** | Feel spiral/back line stretch |
| Muscled swing, no whip | **T/SSC** | Loose takeback, no pause |
| Big takeback, late | **8** | Small 8, continuous |
| Flat, no margin | **45°** | Back pocket → far shoulder |
| Pushy, no penetration | **BRAKE** | Front leg stomp, torso stop |
| Inconsistent under pressure | **JIN** | Ting → Hua → Fa |

## The CORE Loop (Per Shot)

```
1. Q: Eyes park on contact zone at opponent's contact
2. V: Head still, chin tucked through swing
3. ROOT: Back foot screws → front foot braces
4. 8: Continuous figure-8, no pause at top
5. BRAKE: Front leg/hip stops hard
6. PULSE: One-inch push through contact
7. JIN: Feel → Absorb → Release
```

**All six in under 1 second. Automatic. Trained.**
