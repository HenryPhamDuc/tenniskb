# T - Tensegrity

**Bones float. Fascia holds.**

---

## The Principle

Your body is not a stack of blocks. It's a **tent**.

- Bones = poles (they float, never touch)
- Fascia = fabric + guy wires (continuous tension)

Pull one guy wire → whole tent changes shape.

---

## The Rules

| Rule | Meaning |
|------|---------|
| **Bones float** | No bone-on-bone compression |
| **Fascia holds** | Continuous tension network |
| **Tension stays continuous** | No slack, no knots |
| **Tension = integrity** | Tensegrity = Tension + Integrity |

---

## The Two Lines

| Line | Stroke | Structure |
|------|--------|-----------|
| **Spiral Line** | Forehand Push | Foot → hip → oblique → shoulder → arm |
| **Back Line + Lat** | Backhand Saber | Heel → hamstring → sacrum → lat → arm |

---

## The Three Breaks

| Break | Symptom | Fix |
|-------|---------|-----|
| **Tight forearm** | Local knot, line blocked | 3/10 grip, loose wrist |
| **Drifting head** | Tent re-tensions to balance | Quiet Eye + Vestibular |
| **Collapsed arch** | Base pole unstable | Root: tripod + arch lift |

---

## The Feeling

| State | Feeling |
|-------|---------|
| **Intact** | Stretch from foot to hand, continuous |
| **Broken** | Tension pools locally (forearm, shoulder) |
| **Re-tensioning** | Head moves → whole body stiffens |

---

## The Drill

**"Tent Trace"**

1. Stand in hitting stance
2. Slow shadow swing
3. Trace tension line with mind: foot → hip → ribs → shoulder → hand
4. **No slack anywhere.** Continuous tension.
5. If head moves → feel whole line re-tension
6. If forearm tight → feel knot, release

**10 reps each stroke. Feel the tent, not the muscles.**

---

## The Cue

> **"Bones float. Fascia holds. Tension stays continuous. No knots."**
